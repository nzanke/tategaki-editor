縦書きエディタ

複数のPCで共有する（GitHub同期）

記事は下のリポジトリの JSON ファイルに保存されます。トークンは各PCで最初の1回だけ入力します（このPCのブラウザにだけ保存されます）。トークンがなくても、このPCの中には保存されます。

  1. GitHub の Fine-grained token 作成ページを開く
  2. Token name に「縦書きエディタ」、Expiration は好みで（No expiration も可）
  3. Repository access で「Only select repositories」→ tategaki-editor を選ぶ
  4. Permissions の Repository permissions で Contents を「Read and write」にする
  5. 「Generate token」を押し、出てきた文字列を下に貼る
